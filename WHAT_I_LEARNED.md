# What I Learned

While working on this project, I learned how to build and work with REST APIs using Django. I created multiple APIs for products, boxes, orders, and box recommendations.

I also learned how to implement the box recommendation logic, such as calculating the required box size based on product dimensions, checking whether a product can fit inside a box, and considering the weight and quantity of products.

I learned how to use PostgreSQL for storing application data and Redis for caching API results. I also learned how to use Docker and Docker Compose to run Django, PostgreSQL, and Redis together.

I also gained practical experience with API testing using Postman, writing automated tests, running 29 tests successfully, and setting up GitHub Actions for automated testing.

Overall, this project helped me understand how different backend components work together in a real Django application and how to test and verify the application before deployment.
